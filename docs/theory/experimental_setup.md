## 3. The Burgers Equation Setup

**PDE:**
```
∂u/∂t + u·∂u/∂x = ν·∂²u/∂x²

ν = 0.1 (viscosity)
x ∈ [0,1] periodic
t ∈ [0,1]
```

**Operator being learned:**
```
G†: L²_per((0,1); ℝ) → H^r_per((0,1); ℝ)
    u₀(x) ↦ u(x,1)
```

**Dataset:**
- Source: Zongyi Li Google Drive (official FNO data)
- File: Burgers_R10.mat
- Shape: (2048, 8192) — 2048 samples, 8192 grid points
- Generated by: high-precision numerical solver at n=8192
- Downsampled to n=1024 for experiments

**Data preparation:**
```python
subsample = 8192 // 1024   # = 8
a_sub = a[:, ::subsample]  # (2048, 1024)

# Concatenate spatial grid for positional awareness
grid = linspace(0, 1, 1024)
inputs = cat([a_sub, grid], dim=-1)  # (N, 1024, 2) — da=2

# Split
x_train = inputs[:1000]    # (1000, 1024, 2)
x_test  = inputs[-200:]    # (200, 1024, 2)
```

**Why da=2:**
Without spatial grid x, FNO has no positional information.
The Fourier operator is translation invariant.
Including x breaks the symmetry — model knows WHERE it evaluates.
Similar to positional encoding in Transformers.

## 5. The Relative L2 Metric

All paper results measured as:
```
error = ||u_pred - u_true||₂ / ||u_true||₂
```

**Why relative:**
- Scale independent: 1.5% means 1.5% whether SCF=2 or SCF=10
- Prevents high-magnitude samples dominating training
- Physically meaningful: engineers think in percentages

## 6. The Resolution Invariance Remark

**Classical solvers (FEM/FDM):**
```
Error ≈ C · h^p = C · (1/n)^p

p=2 (linear FEM): error halves when n doubles
At n=64:  error ≈ C × 0.000244
At n=256: error ≈ C × 0.0000153
More points → less error → converges to true solution
```

**FNO:**
```
Error ≈ constant regardless of n

Error determined by:
  - Number of training samples N
  - Architecture quality (k_max, dv, T)
  - Fourier basis representation of the solution
NOT by grid resolution n

At n=64:  error ≈ 1.5%
At n=256: error ≈ 1.5%  (same!)
At n=1024: error ≈ 1.5% (same!)
```

**The Nyquist condition:**
n must satisfy n ≥ 2·k_max for FNO to resolve all modes.
Once satisfied, adding more points does not reduce FNO error.
